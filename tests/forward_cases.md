# 自然语言回归清单

这不是 Python 文本匹配能证明的能力清单。新模型或新版 skill 应在加载 SKILL.md 后实际回答下列输入，并根据可观察预期审阅。示例和脚本的自动测试另行运行。

| 输入 / 条件 | 应观察到的结果 |
|---|---|
| 她有些委屈，8秒 | 低强度，不新增痛哭、告白或失控动作；有注视对象 |
| 15秒，微笑→疑惑→难过→释然 | 新信息让前一反应改变，四段有动作过渡 |
| 沿用首帧角色与衣服 | 锁定已知锚点；不冻结姿势；未见图不编造样貌 |
| 两个人递笔记本，6秒 | A递出，B接触握稳，A松开，B收回；左右一致 |
| 不要字幕 / 需要日中双语字幕 | 前者不加字；后者区分对白表演与后期字幕轨 |
| 安静情绪戏 / 骑士战斗 | 前者可稳定镜头；后者写位置、承重、攻防和收势 |
| 15秒里朗诵长段原文 | 不删原文，说明超时，建议延时或分镜而非假称装得下 |
| 上限5000字符并保留台词/服装 | 实测含换行字数；压缩次要说明，不机械截断 |
| 只改男生语气，别改其他句子 | 其他文本逐字保留；只调整该发声描述 |
| 按未上传的参考照片写 | 不声称已查看；需要关键视觉事实时只问一项 |
