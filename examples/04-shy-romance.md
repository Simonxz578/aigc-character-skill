# 04｜她听到心上人叫自己的名字

## 用户输入

她听到心上人叫自己的名字。

## 分类与约束

同一需求的三档对照；成年角色，克制的喜欢与害羞，无泪、无新增告白。时长统一15秒以比较控制信息，实际最短需求也可选择10秒。未给参考，本例原创设定，不声称已分析母版。名字未给，原声音保留为画外轻声称呼，不虚构具体名字。

## concise｜可复制 Prompt

```text
15秒写实关系镜头，成年女子穿浅灰外套，站在书店窗边，心上人在画面右侧画外。中近景固定，柔和窗光照清双眼，手中书册保持原样，无字幕。
0–5秒：听见对方轻声叫自己的名字，她先停下翻页，目光从书页移到右侧，随后才轻转头；吸气有一个短停顿，不突然睁大眼。
5–10秒：确认是在叫自己，她的嘴角轻扬，又因怕被看出喜欢而收小；视线落到对方手的位置，再回到脸上，书页停在原处。
10–15秒：她让呼气完整吐出，把书合好贴在身前，抬眼轻点头回应。肩线放松，笑意仍淡；结束在自然对视，不加泪水、告白、亲吻或额外台词，只保留原称呼和书店底声。
```

## standard｜可复制 Prompt

```text
15秒写实关系镜头。成年女子穿浅灰外套，站在书店窗边，双手拿着一本打开的书；心上人在右侧画外一步多的位置。她希望被对方特别关注，却不想让自己表现得过分急切。窗光从左侧照亮脸，书架背景安静，保持衣服、发型和书的归属不变。开场胸以上中近景，能看见两手与书页，摄影机固定，不加字幕。画外称呼沿用实际输入的声音；未提供名字时不编造名字或可见文字。
0–3秒：对方轻声叫她的名字，她先停下翻页，右手指腹留在书页边缘。目光从页上移到右侧声源，头部随后轻转一点，吸气短暂停住。眼睑略抬，嘴唇微开却没有马上说话，先判断对方是否真的在叫自己。
3–7秒：确认对方正看着她，目光在脸的位置停稳，嘴角忍不住轻扬。她不立即往前走，而是把将要离开页边的右手放回书侧，让喜悦藏在一个平常的动作里。肩线保持自然，没有夸张耸肩或用手捂脸。
7–11秒：她发现自己的笑被对方看见，视线短暂落向对方手边，再回到脸上。嘴角收小，却没有完全消失；唇线放松，轻轻呼出一口气。让害羞表现为想对视又留一点回避，不加脸部突然发红、眼泪或眼球乱转。镜头保持原景别，使观众同时看见她并没有退走。
11–15秒：她把书合好，左手托底，右手扶侧，动作完整后抬眼轻点头。肩线随呼气放松，身体仍站在原窗边，最终主动维持短暂对视。书封面不生成可读字，人物不换装。声音只有原称呼、轻微纸声和书店环境，其他台词不自动添加；不安排告白、拥抱或亲吻，结束在她允许这次关注被自己接住的姿态上。
```

## cinematic｜可复制 Prompt

```text
15秒写实关系片段，一镜到底。成年女子穿浅灰外套，站在书店窗边，双手托着一本打开的书，右手指腹停在即将翻过的页角；心上人在画面右侧画外，距离约一步多。她希望这声称呼对自己有特别的意义，又不愿把一瞬的期待暴露得太急。开场胸以上中近景，两手和书页在画面下方可见，背景书架只提供位置关系。左侧柔和窗光照到她脸颊和两眼，光源与白平衡全程稳定，不因心动改变房间颜色。画外称呼沿用实际提供的声音；名字未提供时不虚构具体名字，也不生成画面文字。摄影机前半段保持机位，后半段仅在她决定回应时轻推，最终保留肩与书册的上缘，让情绪和身体选择都能被看见。
0–3秒：对方轻声叫她的名字。她不是立即转头给出笑容，而是先把翻页的动作停住，右手页角仍接触纸面，纸没有凭空翻过去。目光从书页的行间抬起，先抵达右侧声源，再让头部轻转到可以看见对方的位置。眼睑比开场略抬，嘴唇从阅读时的自然闭合变为很小的开口；一次吸气在中间停了短短半拍，随即继续。她想确认这是否只是普通招呼，目光停在对方脸的高度，没有寻找其他对象，也没有看向镜头。书店底声保持很轻，让称呼清楚，但不放大不可能听见的睫毛或眼球运动声。动作有真实的先后，手没有随转头同时抬到脸边。
3–6秒：她确认对方的目光确实落在自己身上，嘴角才开始轻扬。原本要翻页的右手放下页角，把书页压回原来位置，左手仍托住书底，完成一个让自己显得从容的小动作。笑意很浅，更多来自眼睑放松与目光停留，而非张嘴大笑。她的下颌略微松开，呼气比开场顺畅一点；肩线没有夸张抬高，身体也不马上向对方倾过去。此刻她想继续对视，却还不确定自己能不能把这份开心表现出来，所以让视线多留一瞬，再准备收回。镜头保持中近景，使观众能看见书页真的被她放回，而不是只在面部贴一层笑。
6–9秒：对方在画外耐心等着，她意识到刚才那点笑意已经被看见。目光短暂落到对方手的位置，头部只低一点，嘴角收小却没有完全压平；这是一种保留喜欢的害羞，不是受到惊吓的后撤。她把右手移到书侧，让原本悬着的指尖落到稳定位置，避免连续搓手或抓衣角。呼吸轻而完整，唇线放松，皮肤不突然改变颜色，也不把害羞演成泪意。背景有人轻移一本书，声音仍来自远处，不抢过人物的停顿。侧光在她略低头时自然改变脸部可见高光，光源本身不闪烁，头发只跟随头部轻动。
9–12秒：她决定不再把视线藏回书里，眼睛先重新找到右侧对方，随后抬起头。左手仍托底，右手轻扶书边，缓慢把打开的书合上；纸张与封面接触有很短的轻响，手指不穿过书页，也不在动作中交换左右。嘴角恢复一小点弧度，比最初的笑更稳定，因为这次是主动回应。摄影机从此处极轻缓地靠近，保持交谈轴线与同一侧机位，让对视的选择被放大，推进不超过从中近景到较紧中近景的范围。她不在合书时突然开口告白，不把几个不相干的手势塞进短暂间隙；整个动作先完成，再让身体收稳。
12–15秒：她把书贴近身前但不抱得过紧，双手停稳，然后向对方轻点一下头。肩线随完整呼气放松，视线没有再次匆忙逃开，保留一段自然、短暂的对视。嘴唇合得柔和，淡笑不扩大成展示给镜头的表情，开心也不在最后一秒忽然消失。镜头停止推进，让头发、衣袖和书页的余动自然收住；窗、书架、衣服和人物比例保持一致。声音保留原称呼、纸声与书店底声，不擅自追加台词、配乐或字幕。最后呈现她终于允许自己接受这次关注的姿态，不安排泪水、拥抱、亲吻，也不把两人的关系直接升级。人物仍有细小的呼吸与目光保持，结尾不是静态照片定格。
```
