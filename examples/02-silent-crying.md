# 02｜收好未能入选的作品

## 用户输入

15秒，一位青年修复师发现自己的展览名额被取消，导师还在旁边。他内心崩溃但不愿当场哭，要 cinematic 细描，不能掉泪。

## 分类与约束

写实青年；控制策略是完成手头工作；错愕 → 确认 → 抑制 → 自主收拾。15秒，五节拍，内心强、外显小。无对白、无字幕；纸上不生成可读通知正文。

## 可复制 Prompt

```text
15秒写实人物短片，修复室午后。青年修复师穿深灰工作衫，袖口卷到腕上，短发保持原样；他在桌前坐着，画面左下方是一件已经装入保护盒的小型陶器。导师站在右侧画外，他本来准备把作品交给导师带往展厅。桌面收到一张撤销参展的通知，纸上只保留版式与红色印记，不生成可读正文。青年想问自己究竟哪里做错了，却不愿在导师面前把多年准备说成一次乞求。他的起始姿态是右手托住盒侧，左手持着尚未贴上的封签，目光专注于器物边缘。摄影机从肩胸中近景开始，能看到盒子与双手，沿桌边同侧缓慢靠近；始终保持右侧导师的注视方向，不改工作服，不把室内换成舞台或雨景。
0–3秒：通知被放到保护盒旁，他先看纸上红色标记，再看画外导师，确认它与这次展览有关。右手仍托着盒子，但准备推出的动作停住；左手封签只略微翘起，没有掉落或抖得夸张。眼睑在识别信息时抬高一点，嘴唇留出准备询问的缝隙，吸气却在说话前停下。他不急着低头，也不立刻给出悲痛表情，而是在导师脸的位置多看半秒，等待一句能改变判断的解释。导师没有补充，只把展厅钥匙收回衣袋，钥匙相碰的轻声来自画外。这个实际动作结束了他的期待，使最初的错愕开始转为确证。镜头不因消息突然摇晃，面部与盒子仍处在同一个空间内。
3–6秒：他的目光从导师收钥匙的位置退回通知，再落到自己左手的封签。意识到作品不会被带走，他把封签放到盒盖边上，指腹保持平贴，免得纸条卷起。嘴唇合上，先把想问的问题留住；下颌短暂用力，之后没有马上松开。吸气恢复，但比开场浅，肩膀不跟着耸动。他试图表现得像一次普通的收尾，所以把盒子旋回面对自己的方向，动作只有小幅转动而不是大力拖拽。摄影机这时缓慢靠近，把视线与口周放到更清楚的位置，仍留下右手位置作为身体反应的证据。窗外日光平稳，陶器反射没有变色，情绪不靠照明骤暗替代。纸张摩擦声很短，随他停止动作便结束。
6–9秒：他再次抬眼，却在看见导师已经准备离开时，把未能成句的呼气放轻。眼睛仍有明确对象，不能演成无目标瞪视。嘴角没有礼貌笑的支撑，慢慢回到自然平直；下眼睑开始出现一层不显眼的水光，面颊保持干燥。他把右手从盒侧挪到盖缘，手掌停稳之后才让手指放松，像要借一个完整的工作动作稳住自己。左手没有另外揉眼或捂嘴，身体不同时发出一套崩溃信号。此刻观众看见的是他努力保留职业姿态，而不是他已经没有感受。镜头继续保持同轴近景，让眼里的湿润与仍然可靠的手形成关系，不追逐皮肤纹理或制造呼吸式焦点抽动。
9–12秒：导师的脚步逐渐远去，他的视线跟到门口，停在门边最后能看见人的位置。门扣合上后，他才垂下眼帘，把已经贴近盒盖的右手停住一瞬。下颌松开，呼气比此前长一些，但没有叹得像舞台表演；鼻翼跟着真实呼气轻动一次，不加入单独的抽泣动作。下眼睑的水光仍在，眼睛并不因为门关上立即流泪。他想允许自己难过，却知道器物还没有收妥，于是把注意力重新落回盒缘，确认盖子与底座对齐。相较前面的克制，这里只泄露一个小停顿和一个完整呼气，避免五官同时大幅收缩。室内只剩通风设备的低声，镜头不额外配悲怆弦乐，也不给眼泪或目光移动添加声音。
12–15秒：他慢慢合上保护盒，确认盖子落稳，再把封签放回工具盘，放开两手。动作完成后，掌心停在桌面，不再借整理工作掩盖情绪。目光留在盒上，像承认此刻无法把它交出去；眼睑放松一些，嘴唇自然微开，呼吸重新接成完整的一次。最后半秒他抬眼看向窗外的亮处，不追随不存在的人，也不忽然笑起来。这不是已经释然的胜利，而是先把眼前一件事做好，再允许自己安静坐着。摄影机停止靠近，保持自然头部空间与稳定肩线；衣服、发型、保护盒及器物归属没有变化。全程无对白和字幕，不落泪、不失声、不揉碎通知；保留门扣、纸张和轻微室内底声。结束时泪意可以仍然可见，呼吸不必完全匀称，但动作已有清楚终点。
```
