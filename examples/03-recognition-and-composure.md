# 03｜陌生人的一句称呼

## 用户输入

9秒，男主在旧书店里突然发现陌生人认出了自己，震惊后强装镇定，不要大叫。

## 分类与约束

悬疑 / 写实；防御型人物；身份被识破 → 复核 → 完成原动作。9秒，三节拍，standard。原创设定；不加追逐、武器或身份换脸。

## 可复制 Prompt

```text
9秒写实悬疑人物镜头。成年男子穿褐色夹克，站在旧书店柜台左侧，右手拿着刚选中的旧地图册；陌生店员在右侧柜台后。男子以为自己只是普通顾客，想在不引人注意的情况下离开。开场中近景同时看见他的脸、书和柜台，两人左右位置固定。光来自左侧高窗，书架暗部保留层次，环境安静，没有刻意阴森的闪光。
0–3秒：店员看见地图册封面，抬眼对他说：“你终于回来了。”男子准备把书放下的动作停在柜台上方，目光从书沿移到店员脸上，眼睑略抬，嘴唇微开却没有立即回答。他先确认这句话是否真在对自己说，头部只跟随视线转动少许。书仍握在右手，没有突然掉落。
3–6秒：男子看向店员身后的门，再回到店员，意识到没有别人。右手把书真正放到柜台上，指腹暂时留在封面边缘；下颌短暂收紧，呼气后把嘴唇合上。他想追问，却选择不暴露自己已被认出。摄影机只轻推少许，让这次复核和完成动作看得更清楚，不绕到另一侧。
6–9秒：他从衣袋拿出书款，平放到书边，抬眼问：“这本多少钱？”音量自然偏低，句子完整，尾音不故作冷酷。说完后手离开钱，肩线恢复原来的高度，但视线仍留在店员脸上，不仓促逃开。让镇定表现为把普通买书流程继续做完，保留前一瞬的不安。声音只有两句对白、纸币轻响与书店底声；无字幕，人物衣服、面容和书的归属保持一致，不加尖叫、泪水或突发动作。
```
