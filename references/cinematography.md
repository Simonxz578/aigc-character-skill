# 镜头与空间

| 场面 | 镜头选择与目的 |
|---|---|
| 单人情绪 | 先稳定中近景交代手与注视对象，必要时轻推到近景，给情绪选择更多重量 |
| 双人关系 | 建立谁在左右、谁看向谁；同轴切反应，视线高度和方向对应 |
| 递物 | 让接触点可见，别切走掩盖交接；双方手臂有起止位置 |
| 战斗 | 全/中景说明路线，近景只在实际停顿，返回后动作方向一致 |
| 写字 | 先看到纸面与两手，再到侧脸；焦点迁移发生在笔尖稳定后 |
| 舞蹈 | 留脚下支点，跟随动作收势，别只拍脸丢掉拍点 |

“固定机位”和“推进”是不同摄影决定。若要机位固定但主体在动，直接写人物运动；不要同时要求零位移、手持晃动和慢推。无剪辑的一镜也可推进，但需写清。

景别与镜头焦段是方向参考，不是渲染物理保证。近景不能把双手交接放在画外同时要求验收手指。浅景深保留足够双眼与关键道具可读性，焦点不无故来回跳动。

光来自明确方向：窗、灯、月、火等。情绪转折不自动让太阳换位置。风影响衣摆、草叶与发梢，应同向且强度一致。亮度、雾和反光不能遮掉要观察的动作。

已有首帧：保留人物、衣服、道具归属和建筑/桌案等空间锚点；连续运动不是冻结初始姿势。未见参考：写“沿用你提供的母版”，明确待参考实际输入，不编造颜色、脸型或已经核对过的构图。
