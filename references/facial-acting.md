# 面部、视线与呼吸

按镜头可见程度选焦点。一段通常只有一个主动作、一个辅助动作；其余面部保持自然，不逐一指挥全部肌肉。

| 焦点 | 可执行写法 | 避免 |
|---|---|---|
| 注视 | 看对手左眼 → 看对方手里的信 → 回到脸；先目光后转头 | “眼神充满故事”而没有对象；眼球无因滚动 |
| 失焦 | 看着车门反光却未追随倒影；被叫后重新落到人脸 | 把失神写成眼球翻白 |
| 眼睑 | 识别消息时抬起；压住话时垂下；确认后放松 | 所有情绪都瞪眼 |
| 眨眼 | 听见新事实后延迟一瞬，再自然眨一次 | 每秒同样频率眨眼；连续密集眨动制造闪烁 |
| 眉 | 原来上挑的眉尾回落，或疑问时一侧微抬 | 强制整段绝无任何自然皮肤褶皱 |
| 泪意 | 下眼睑出现薄水光；眼睛仍明确看向对方 | “悲伤所以瞳孔缩小”；泪在两秒内蒸发 |
| 嘴角 | 礼貌笑在对方转身后放平 | 几十种嘴角方向同时变化 |
| 唇颌 | 想开口而合上；下颌用力后呼气松开 | 台词期间不断抿唇、吞咽打断口型 |
| 鼻与呼吸 | 一次吸气不完整，鼻翼随其轻动；之后完整呼气 | 把每个鼻部小动作当情绪密码 |

呼吸声只在录音距离和环境允许时可听：近景安静室内可有轻呼气；风大远景主要保留环境。吞咽可以有轻微可见动作，不强加巨大的吞咽音。睫毛或目光移动不产生可听音效。

二维动画用眼形开合、瞳仁注视对象、嘴部线条与肩线表达。除非画风支持，不要求真人血丝、毛孔、唇纹。远景把细节换成头部转向、距离和重心；不要承诺看清微米级运动。

含泪但不落泪：建立压制原因，选减少眨眼、换注视点、把话停住等动作；不能命令人物“锁住眼泪肌肉”。泪光保持克制，不变成不断跳动的高光粒子。镜头与照明变化可影响可见程度，但不等于眼泪消失。
