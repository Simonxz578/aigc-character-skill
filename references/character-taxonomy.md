# 多轴分类：角色如何调节情绪

分类用来选择动作，不作为最终 Prompt 的标签堆叠。先选人物控制习惯，再选情绪弧线、场景尺度和镜头可见焦点。

## 人格与控制策略

| 轴 | 可观察差异 | 对手在场时的改变 |
|---|---|---|
| 外放 / 内敛 | 先说话寻求回应 / 先看道具整理想法 | 外放也可能突然停句；内敛也可能选择正面注视 |
| 理性 / 冲动 | 复核信息后动作 / 手先动、意识到后收回 | 前者解释顺序更清楚，后者需要一个收势 |
| 坦率 / 防御 | 呼吸后直说 / 用工作动作转移话题 | 防御者回答事实，避开关系问题 |
| 成熟 / 青涩 | 留出对方空间 / 急于确认又怕显露 | 青涩可借物件掩饰，成熟可主动结束等待 |
| 矜持 / 大方 | 收小动作和接近幅度 / 对视与距离更直接 | 两者都可以难过，区别是如何恢复分寸 |
| 温柔 / 锋利 | 先确认对方感受 / 先指出矛盾 | 温柔也能坚定；锋利也会保护他人 |
| 克制 / 失控 | 延迟反应、动作完整 / 中断原动作、失去节奏 | 失控必须由足够强的事件支撑 |
| 主动 / 退缩 | 发起目光或递物 / 等待对方先行动 | 弧线可用一次主动行为标出改变 |

挑一个特有习惯，如捋平纸边、把杯子摆正或说话前向左呼气。重复习惯要发生改变才有叙事价值，不为每个情绪发明一个新的小动作。年龄、性别和服装不决定人格。

## 情绪组合索引（44 种）

每行由触发、控制和可见证据组成；按强度与角色调整，不直接照搬。

| 情绪 | 触发与控制 | 可见证据 |
|---|---|---|
| 安心 | 不确定得到确认，终于不再监听 | 视线稳定，肩线随呼气放下 |
| 欣慰 | 对方完成曾经做不到的事，避免邀功 | 看向成果，再看对方，轻点头 |
| 窃喜 | 得到私下回应，想藏住开心 | 先低头，嘴角只在转开时扬起 |
| 欣喜若狂 | 长期等待结束，暂时放下控制 | 重心向前、展开手臂；需用户支持此强度 |
| 得意 | 自己的选择被证明，保留礼貌 | 下颌略抬，短暂确认对方反应 |
| 强装开心 | 不愿令他人担心 | 笑容先到，回答慢半拍，收声后嘴角放平 |
| 暗恋 | 对方靠近，怕被看穿 | 看向对方手中物件，延迟直视 |
| 试探 | 想确认关系，又留退路 | 递出问题后停下动作，等完整回答 |
| 怦然心动 | 发现对方记得小事 | 吸气中断，目光停住，后才回笑 |
| 害羞 | 关注落在自己身上 | 视线移向旁侧，肩不夸张耸起 |
| 嫉妒 | 他人获得特殊关注，维持体面 | 停下原动作，答句简短，目光回到自己的任务 |
| 依赖 | 遇到压力，允许求助 | 靠近半步，等待对方示意再停稳 |
| 释怀 | 接受无法改变的事实 | 手松开原本握紧的物件，目光重新落定 |
| 告别 | 时间已到，避免拖住对方 | 转身前保留一次对视，脚步随后启动 |
| 失落 | 期待未兑现 | 原先准备好的动作停住，再有意收回 |
| 委屈 | 努力被误读，不愿争辩 | 欲言时抬眼，见对方没听而闭口 |
| 心痛 | 关系的事实被证实 | 下颌短暂收紧，呼气更慢，不必有泪 |
| 怀念 | 熟悉物件唤起往事 | 指腹停在磨损处，目光从细节回到远处 |
| 悲恸 | 不可逆的失去，控制难以维持 | 呼吸和说话节奏断开，身体需要支撑 |
| 强忍泪水 | 不愿在对方面前失去控制 | 减少眨眼，停句，呼气后重新注视 |
| 哭泣后平静 | 情绪已释放，需要恢复 | 擦过脸颊后手放下，呼吸逐渐完整 |
| 冒犯 | 边界被侵犯，先核实 | 目光直视，身体停止前倾 |
| 压抑怒意 | 对手尚在，任务更重要 | 稳定音量，手指压住桌边，等门关上 |
| 讽刺 | 看穿借口，保持礼数 | 单侧嘴角短暂抬起，话尾停得干净 |
| 冷怒 | 已作决定，拒绝争论 | 注视不逃避，动作减少，结束对话 |
| 爆发 | 累积边界被再次突破 | 站起有脚下支点，声音与动作同步增强 |
| 愤怒中的脆弱 | 辩解显出受伤 | 强硬句尾变轻，视线第一次回避 |
| 紧张 | 即将受评价 | 提前吸气，握稳工具，确认入口 |
| 戒备 | 意图不明者接近 | 身体侧开，留出退路，眼神跟踪对方手 |
| 惊吓 | 突发声或逼近 | 短促后撤、随后识别声源；不是长期睁大眼 |
| 强撑镇定 | 不愿暴露自己已被识破 | 先停顿再完成原动作，语速刻意稳定 |
| 惊恐后的麻木 | 冲击后处理能力暂时下降 | 看向明确对象但回应延迟，手停在途中 |
| 疑惑 | 信息不完整 | 目光在两条证据之间移动，轻偏头 |
| 怀疑 | 解释与事实冲突 | 再看关键细节，暂不接下对方物件 |
| 顿悟 | 两条线索相连 | 目光由物件转回对方，原先问题不再问出 |
| 错愕 | 预期被突然推翻 | 动作短暂停住，眼睑抬起，随后复核 |
| 不可置信 | 消息影响重大 | 再问一句确认；不机械摇头十次 |
| 被误会 | 对方归因错误 | 想解释而看见对方已经转身，话留在口边 |
| 悔意 | 知道自己的选择伤害他人 | 正面面对事实，手停止遮挡关键证据 |
| 喜极而泣 | 放松控制后喜悦溢出 | 笑意先出现，呼气中泪光形成；需允许泪水 |
| 哭笑不得 | 双重结果同时成立 | 短笑后叹气，目光落向造成困境的物件 |
| 爱恨交织 | 想靠近又记得伤害 | 前移半步后停住，手留在双方之间 |
| 笑中含泪 | 开心与不舍并存 | 嘴角维持小幅笑，眼部水光并不快速消失 |
| 得意转委屈 / 愤怒转无力 / 惊喜意识到代价 | 新证据改变原先理解 | 原有动作完成或收势，再转向新注视点；分别使用而非一次连演三种 |

## 场景尺度

| 类型 | 表演与摄影选择 |
|---|---|
| 恋爱 / 日常 / 初遇 | 看与不看、物件交接、交谈距离；不擅自升级为告白 |
| 误会 / 告别 / 家庭 / 友情 | 让对方动作改变自己的判断，留一个主动回应 |
| 职场 / 权谋 / 谈判 | 明确信息差、公开姿态和私下泄露，不靠怒吼代替策略 |
| 古风 / 戏曲 | 袖、礼、身段有物理支点；戏曲程式需用户指定，古装不自动慢动作 |
| 悬疑 / 恐怖 | 识别声源、退路和遮挡，恐惧由事件发生而不是黑色滤镜 |
| 历史人物 | 已知史实与艺术化情境分开，不伪造名人原话 |
| 校园 / 青春 | 保持指定年龄，关注迟疑与关系分寸，不强加幼态 |
| 日漫 / 二维 / 奇幻 / 游戏 | 轮廓、色块、动作线、法术作用方向；身份比材质噪声重要 |
| 电影写实 | 人体重量、呼吸和镜头距离一致，近景不过密解剖肌肉 |
| 舞蹈 / 歌唱 | 先有拍点、换气和脚下路线，再让情绪改变动作完成度 |
| 战斗 / 对峙 | 攻防路径、支撑脚、惯性与空间；情绪特写要接在实际停顿 |
| 双人关系 / 无对白独白 | 因果反应和注视对象清楚；无对白仍可有环境声 |
