# 平台写作侧重点

本表是文字组织建议，不是平台能力声明。它不确认某个型号已经上线，也不提供价格、最大时长、帧率、参考上传数量或编辑能力。名称来自用户时可保留其目标标签；实际制作前到平台官方文档核实可用型号、输入方式和限制。

| 目标标签 | 写作侧重点 |
|---|---|
| Seedance 2.5 / 2.0、小云雀 | 一份中文正文按镜头、主体、动作、表演、环境、声音与必要限制组织；参考编号只用界面实际支持的形式。所谓“2.5”不作为已经核验的官方可用型号结论 |
| Kling | 把初始姿态、运动路径、交接终态写清，控制一段里动作数量；按实际界面处理参考，不编造专用开关 |
| Veo | 明确场景、人物行为、镜头与可听事件；用户有对白时写原话与语言，声音是否原生支持需核实 |
| Sora | 稳定空间关系与事件先后，明确一镜或多镜；不假定某个账户支持人物复用、编辑或长片 |
| 通用 | 中文优先；需要英文时翻译同一控制信息，不增加剧情；用动作代替形容词 |

## 原片局部修订

说明允许变化的对象、区域、时段与维度，沿用其他镜头/人物/场景/音轨；不要命令全场每个元素绝对静止来保护连续性。该 Prompt 不能保证像素级局部替换；有这种要求时，交由遮罩、跟踪、合成等确定性后期工作流，且要可用工具支持。

## 文字与音轨

精确字幕、片名、书写文字和原声音轨由后期确定性处理。生成 Prompt 可以描述无字纸面、自然笔画或讲话动作，不能将自然语言约束包装成逐字无误或音轨完全保留的技术保证。

Prompt模式只负责提示词，不顺带调用生成服务。2.0的生产模式可使用已有且获授权的视频工具，以及仓库提供的本地配音/ComfyUI接口与FFmpeg后期；模型和运行时需单独准备，不自动使用付费fallback。生成结果按实际媒体另外验收，具体路由见[生产流程](production/workflow.md)。
