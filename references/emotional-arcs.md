# 情绪弧线与控制

先问：人物希望对方做什么、为何此刻不直接请求？变化必须来自新信息或自己的决定，而不是秒数到了就换表情。

## 常见结构

| 弧线 | 触发与可见转折 |
|---|---|
| 微笑 → 疑惑 → 难过 → 释然 | 收到肯定而笑；看到未署名的信而疑惑；认出告别日期而笑停；决定不挽留，主动把信收好 |
| 震惊 → 强撑镇定 | 陌生人准确说出身份；人物停止原动作；复核对方；完成手头动作恢复社交姿态 |
| 窃喜 → 意识到代价 → 含泪接受 | 私下认可；现实的离别信号进入感知；克制避免使对方自责；主动完成交接 |
| 愤怒 → 无力 | 有证据反驳；发现对方不愿听；停止辩论；把精力转向能做的事 |
| 误会 → 确认 → 缓和 | A 提出证据，B 复核，B 主动回应，A 在收到回应后才放松 |

控制强的人也会在小地方泄露：回答晚半拍、手没能立刻放开、目光停在已经离开的位置。强情绪不必提高外显幅度。控制下降则要有触发及恢复过程。

## 节拍预算

- 4 秒：一个事件和一个选择，例如听见名字 → 回望。不要塞害羞、痛哭、和解三次反转。
- 8–10 秒：三段通常足够，至少给最终姿态半秒收稳。
- 15 秒：4–7 段，按信息和动作耗时划分，不固定每两秒一段。
- 30 秒：把完整空间动作与表情特写分开；特写在动作收势/掩护时出现。
- 60 秒以上：先列弧线与各镜头时长，再逐镜头给词；平台能否拼接/延长另行核实。

## 低强度保护

“有些委屈”默认只减少笑意、收回原动作、再看对方一次。不要追加落泪、发抖或崩溃。只有明确的情境或要求支持时，才升级。无泪是外显限制，不是“内心没有情绪”。

## 收尾

完成一个选择而非强行治愈：放开物件、让出路、坐稳或重新呼吸。含泪的眼睛在最后两秒不能凭空恢复干燥，未解决的关系也不必忽然开心。余味来自残留姿态与视线，不靠诗意形容词收尾。
