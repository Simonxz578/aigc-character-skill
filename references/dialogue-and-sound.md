# 台词、口型和声音

## 时长预算

自然中文大约每秒 3–5 个音节，情绪戏还需要句前吸气、停顿和对手反应；这只是排练估计。保留用户原话，先分配发言区间，再给反应时间。15 秒里 80 字以上通常需要检查，而不是把它们全部安排在末尾 3 秒。脚本仅按字符做粗提示，不理解所有语言或韵律。

发言时写注视对象与语气变化，如“先看桌上的信，说前半句；停一下，抬眼说完”。别在同一时刻加抿唇、吞咽、闭口并要求完整台词。自然声线用可执行描述：清晰、轻/厚、语速、句尾、气息和情绪；没有真实授权的声纹素材时，不宣称完成任何人的克隆。

## 三个不同开关

| 条件 | 实际意思 |
|---|---|
| 无对白 | 人物不说词，仍可有环境与动作声 |
| 完全无声 / 静音 | 音轨没有声音；不再写音乐、呼吸音和台词 |
| 不要字幕 | 不生成画面文字；人物仍可讲话 |

日中双语字幕：表演 Prompt 保留指定语种原话，翻译与双语字幕属于后期字幕轨或确定性烧录；不能承诺视频模型逐字生成无误的中日文字。用户要求原音轨不变时，明确音轨沿用原片，局部画面改动不能自动重配音。

## 声学可执行性

衣料摩擦、脚步、门扣、纸张、笔尖、可听距离内呼吸可用。耳坠轻摆不必响；目光、睫毛、泪光不配伪音效。强风场景近乎听不到轻吞咽，不因特写视觉就假定录音必定很近。音乐若不是用户要求，短小 Prompt 不自动增加煽情配乐。
