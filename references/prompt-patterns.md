# 长度与输出模式

## 组织方式

先写时长、画风、人物和空间锚点；接着按秒写“事件 → 主动作 → 辅助泄露 → 收势”。最后写必要的声音和针对性限制。人物有意掩饰什么可通过动作说明，不在每段重复“内心很复杂”。

concise 180–350 汉字：保留触发、三个以内节拍、一个镜头选择和关键锚点。standard 450–900 汉字：增加对手位置、控制原因、动作过程、终态及必要环境。cinematic 1100–1700 汉字：只在用户明确要细描时，加可见细节、非冲突的焦点、呼吸和余态；复杂角色也不需要每秒改变表情。15 秒典型对比见 [三档例子](../examples/04-shy-romance.md)。

custom 使用字符上限而非汉字上限：算上标点、拉丁字母、空格与换行。预算顺序：台词与身份/服装 → 事件/交接因果 → 时序 → 镜头 → 环境 → 修辞。删除低优先级段落，不机械截尾。极小上限无法容纳所有必保留项时说明冲突并给最短完整版本，不能假称满足。

## 模式骨架（按需要组合，不机械填表）

| 模式 | 交付内容 |
|---|---|
| prompt_only | 直接正文，一次复制，不显示分类/评分 |
| cinematic_timeline | 稳定锚点；连续时间段；各段镜头和主次动作 |
| dialogue_performance | 原话；发言时段；语种/气息/停顿；听者反应 |
| dual_character | 左右/关系；A 与 B 所知；因果反应；接触与松手 |
| character_sheet | 参考可确认项；日常基线；情绪控制习惯；可变/不可变项 |
| refine_existing | 无关文本原样保留；只改请求的动作/语气/维度 |
| qa_report | 问题 → 可观察影响 → 一条修正；有需求才附重写 |

一份 Prompt 可以是 dual_character 的结构加 cinematic_timeline 的时序，但不要输出两份互相冲突的正文。用户只要词时，不加标题、代码围栏、注释或自评。
